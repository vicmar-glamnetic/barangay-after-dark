# Ambience recordings

Drop CC0 (public domain) recordings here with these names; anything missing
keeps the game's synthesized sound:

| file              | plays                                              |
|-------------------|----------------------------------------------------|
| `rooster.mp3`     | a rooster crowing by the chicken coop, every 1-2 min |
| `kids.mp3`        | kids playing/laughing far away, every ~1 min        |
| `crowd.mp3`       | looping chatter at the titas' chismisan table       |
| `dogs.mp3`        | dogs barking in the distance                        |
| `crickets.mp3`    | looping night insects (still fades in and out)      |
| `motorbike.mp3`   | a motorbike/tricycle passing on the main road       |

Keep each under ~30 s and ~500 KB (mono 96 kbps MP3 is fine). Loops
(`crowd`, `crickets`) should loop cleanly. Credits go in `CREDITS.md`.
